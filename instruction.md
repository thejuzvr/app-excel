# Инструкция по добавлению новых переменных

Любая колонка, добавленная в первую строку Excel-файла с сотрудниками, автоматически становится тегом для шаблонов Word (`.docx`) и Excel (`.xlsx`): `{{Имя_колонки}}`.

## Популярные дополнительные переменные

### Документы и идентификаторы
- `{{СНИЛС}}` — номер СНИЛС
- `{{ИНН}}` — ИНН сотрудника
- `{{Код_подразделения}}` — код подразделения паспорта
- `{{Место_рождения}}` — место рождения по паспорту
- `{{Гражданство}}` — гражданство (РФ, Таджикистан и др.)
- `{{Пол}}` — пол (мужской / женский)

### Трудовой договор и условия
- `{{Дата_приема}}` — дата приема на работу
- `{{Номер_договора}}` — номер трудового договора
- `{{Дата_договора}}` — дата заключения договора
- `{{Оклад}}` — размер оклада / тарифной ставки
- `{{Испытательный_срок}}` — срок испытания
- `{{График_работы}}` — режим / график работы

### Банковские реквизиты (для зарплаты)
- `{{Номер_счета}}` — расчетный счет (20 цифр)
- `{{Банк}}` — наименование банка
- `{{БИК}}` — БИК банка
- `{{Корр_счет}}` — корреспондентский счет

### Миграционный учёт
- `{{Миграционная_карта_серия}}` — серия миграционной карты
- `{{Миграционная_карта_номер}}` — номер миграционной карты
- `{{Дата_въезда}}` — дата въезда в РФ
- `{{Срок_пребывания_до}}` — срок действия регистрации
- `{{Кем_выдан_патент}}` — орган, выдавший патент

### Контакты
- `{{Телефон}}` — номер телефона
- `{{Email}}` — электронная почта
- `{{Адрес_фактический}}` — адрес фактического проживания

## Автоматическое форматирование дат
Если заголовок столбца содержит слова **дата**, **date** или **действителен** (например, `Дата_медосмотра`, `Действителен_с`), генератор автоматически преобразует значение в формат `ДД.ММ.ГГГГ`.

## Как использовать
1. Добавить новый столбец в первую строку файла Excel (например, `СНИЛС`).
2. Заполнить данные по сотрудникам.
3. Вставить тег в шаблон Word (`.docx`) или Excel (`.xlsx`) в двойных фигурных скобках: `{{СНИЛС}}`.
4. Для ячеек в Excel с длинным текстом (адрес, кем выдан паспорт) рекомендуется включить свойство «Переносить текст» (*Wrap text*).
5. Запустить генерацию. Правки в программный код вносить не требуется.
