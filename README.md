## 🌟 Основные возможности

- 👥 **Удобная работа с базой сотрудников**:
  - Загрузка таблиц Excel (`.xlsx`, `.xls`) любого размера.
  - Живой поиск и фильтрация в реальном времени по ФИО, должности и любым колонкам.
  - Множественный выбор сотрудников (кнопки «Выбрать всех», «Снять выбор», выбор через `Ctrl` / `Shift` + клик).
  - Отображение счетчика выбранных сотрудников.

- 📑 **Универсальные шаблоны (Word & Excel)**:
  - Поддержка шаблонов документов Word (`.docx`) и таблиц Excel (`.xlsx`).
  - Автоматическое распознавание переменных вида `{{Имя_колонки}}` из шапки таблицы Excel.
  - Любая колонка, добавленная в первую строку Excel, мгновенно становится доступным тегом без правок кода.
  - Фильтрация шаблонов по названию, одиночный и массовый выбор.

- 📅 **Гибкая настройка даты заполнения**:
  - Встроенный интерактивный календарь для выбора даты.
  - **3 стиля форматирования даты**:
    - `Числовой`: `29.07.2026`
    - `Прописью`: `29 июля 2026 г.`
    - `Официальный`: `«29» июля 2026 г.`
  - Автоматическая подстановка в теги `{{дата}}`, `{{Дата}}`, `{{дата_заполнения}}` и т.д.

- ⚙️ **Форматы экспорта и структурирование**:
  - **Word / Excel**: исходные заполненные документы.
  - **Только PDF**: автоматическая фоновая конвертация в PDF.
  - **Word / Excel + PDF**: сохранение обоих вариантов.
  - Автоматическая сортировка: для каждого сотрудника создается персональная подпапка с его документами.

- 🎨 **Современный пользовательский интерфейс**:
  - Полностью адаптивный интерфейс на **CustomTkinter**.
  - Переключение тем: **Тёмная (Dark)** и **Светлая (Light)**.
  - Автоматическое сохранение пользовательских настроек (папка сохранения, формат документов, тема, стиль даты) в `settings.json`.

- 🔄 **Встроенная система автообновления**:
  - Проверка новых релизов через **GitHub Releases**.
  - Фоновая тихая проверка при старте программы и кнопка ручной проверки.
  - Скачивание обновления с индикацией прогресса и скорости.
  - **Безопасная установка**: обновление не затрагивает и гарантированно сохраняет локальные файлы шаблонов (`templates/`), базы данных (`data/`) и настройки (`settings.json`).

- 🔒 **Конфиденциальность и безопасность**:
  - Папки с шаблонами организации, персональными данными сотрудников и служебными логами изолированы от системы контроля версий (`.gitignore`).

- 🤖 **CI/CD Автоматизация**:
  - Настроенный GitHub Actions workflow: автоматическая компиляция и публикация нового релиза при пуше тега версии.

## 🚀 Быстрый старт

### Вариант 1. Запуск готового приложения (для пользователей Windows)

1. Перейдите на страницу **[Релизов GitHub](https://github.com/thejuzvr/app-excel/releases)**.
2. Скачайте архив последней версии: `Yahoo-vX.Y.Z.zip`.
3. Распакуйте архив в удобную папку.
4. Поместите ваши шаблоны документов (`.docx`, `.xlsx`) в папку `templates/`.
5. Запустите файл `Yahoo.exe`.

---

### Вариант 2. Запуск из исходного кода (для разработчиков)

#### Требования:
- Python 3.11 или новее
- Операционная система Windows (требуется Microsoft Word для конвертации в PDF)

#### Шаги установки:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/thejuzvr/app-excel.git
   cd app-excel
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Запустите программу:**
   ```bash
   python app.py
   ```

## 📝 Руководство по работе с шаблонами и тегами

### Создание тегов в шаблоне Word (`.docx`):
Откройте документ Word и используйте двойные фигурные скобки с названием колонки из Excel:
```
Я, {{ФИО}}, паспорт: серия {{Паспорт_серия}} № {{Паспорт_номер}},
прошу принять меня на должность {{Должность}} с {{Дата_приема}}.
Дата подачи заявления: {{дата}}
```

### Автоматические переменные:
| Тег | Описание |
| :--- | :--- |
| `{{ФИО}}` | Фамилия, имя и отчество сотрудника |
| `{{Должность}}` | Должность сотрудника (поддерживает синонимы `Профессия`, `ДОЛЖНОСТЬ`) |
| `{{Подразделение}}` | Подразделение / отдел / участок |
| `{{дата}}` / `{{Дата}}` | Дата заполнения, выбранная в интерфейсе (в выбранном стиле) |
| `{{Номер_договора}}` | Номер договора / трудового договора |
| `{{Имя_колонки}}` | **Любая** другая колонка из загруженного Excel-файла |

> 💡 **Автоформатирование дат из Excel:**  
> Если название столбца содержит слова `дата`, `date`, `действителен` или `действует` (например, `Дата_рождения`, `Действителен_до`), генератор автоматически отформатирует дату в читаемый вид `ДД.ММ.ГГГГ`.

## 📦 Сборка исполняемого файла (.exe)

Для сборки проекта в автономное приложение используется **PyInstaller**:

```bash
# Установите PyInstaller
pip install pyinstaller

# Соберите проект по спецификации
pyinstaller -y Yahoo.spec
```

Собранная программа будет находиться в папке `dist/Yahoo/`.

## 🔄 Как выпустить новую версию (GitHub Release)

Проект настроен для **автоматической сборки и публикации релизов** с помощью GitHub Actions:

1. В файле `config.py` увеличьте номер версии:
   ```python
   APP_VERSION = "1.0.2"
   ```
2. Зафиксируйте изменения и создайте Git-тег:
   ```bash
   git commit -am "Релиз версии 1.0.2"
   git tag v1.0.2
   git push origin main --tags
   ```
3. **GitHub Actions сделает всё остальное:**
   - Запустит чистую виртуальную машину Windows.
   - Установит зависимости и скомпилирует приложение через PyInstaller.
   - Запакует сборку в архив `Yahoo-v1.0.2.zip`.
   - Опубликует релиз на GitHub.
4. Все пользователи предыдущих версий увидят предложение обновиться прямо в программе!
